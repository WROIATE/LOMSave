## 自动验证

- 26 组回归通过；其中存档可用性策略最终包含 86 项断言，覆盖打字中、文中暂停、自动对白、普通选项、演出、骰子、养成处理中及不支持场景。
- 473 处原生引用、174 个 Harmony 目标、81 处反射成员解析成功，25 个补丁类注册成功。
- 按钮刷新只检查缓存控件和当前对话、动画状态，按 80ms 节流；不生成快照、序列化存档、扫描资源或读写文件。实际点击保存时仍重新检查。

## 实机验证

- 开场“附和三师兄／唯唯诺诺”普通选项可手动保存、读回并选择；恢复目标为 `ch1_1` 第 364 点，状态差异为 0，历史语句执行数为 0。
- 选择后的稳定对白可保存、读回并继续下一句；恢复目标为第 380 点，状态差异为 0，历史语句执行数为 0。两次恢复遮罩约 1.08、1.15 秒。
- 骰子判定页存档按钮预先置灰且有锁图标，旁边显示“判定进行中，请使用最近分支存档”；点击无写入、无弹窗。修正后只保留一处提示，见 [截图](save-disabled-inline.jpg)。
- 原生养成地图可从储存入口保存，日志确认 `mode=native, scene=Free`。地图初始化期间提示“行动处理中”，完成后按钮恢复可用。
- 字体与旁注位置用判定页实机确认；打字、平移的细分判定由策略测试及原生接口检查覆盖，未单独截取其瞬时禁用画面。

测试仅使用原空白槽位。测试文件已归档，原有 107 个存档及附属文件、9 个配置文件已按备份哈希恢复；重启时 Steam 回填的测试文件也已处理。游戏最后回到最初选项，贡献 30、心相 50、行动 4、银两 23000，见 [进度恢复截图](user-progress-restored.jpg)。
