# 0.22.6 选项预览分析性能优化（待实机验证）

日期：2026-10-19，Asia/Shanghai。

## 最近一次卡顿的证据

0.22.5 本机运行日志中，进入武林大会休息页面 `ch6_5_2_break_start_01` 时，剧情快照完成到选项影响分析日志之间分别间隔：

| 本地结束时间 | 同一帧内的间隔 |
| --- | ---: |
| 03:12:13.179 | 6,319 ms |
| 03:13:00.692 | 6,178 ms |
| 03:13:14.143 | 6,322 ms |

各段起止日志的 frame 相同，说明这段加载处理阻塞了游戏主线程。范围包含预览挂钩读取资源及静态扫描，不能据此把之后所有无日志时间都算作 MOD 计算；也没有出现上一版的重放黑屏路径。

该脚本有 15 个选项。旧扫描器为每个选项、每条后续路径重复读取及解析相同大脚本，离线重现共调用资源加载函数 48 次。

## 优化

- 单次扫描中共享不可变语法树及资源读取结果；返回同一根脚本的路径复用根语法树。
- 保留每个选项、分支独立的路径访问记录、递归深度和预算，不合并互斥分支的影响。
- 对完整剧情资源增加最多 32 项的原始动作缓存；重复进入时直接复用。缓存源码变化时失效，不缓存基于当前属性、旗标计算的说明或触发条件。片段脚本仍单独分析。
- 分析日志记录实际耗时及缓存命中，便于后续在 Unity 运行环境复核。
