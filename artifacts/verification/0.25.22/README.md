# 0.25.22 新版游戏离线适配（2026-10-27）

目标游戏：release_1.0.6001.0，Steam build 26237817。按用户要求未启动游戏；以下均为静态检查、编译或离线回归，不代表已完成实机验收。

## 确认并修复的问题

- 冷启动事件索引绑定旧版本；6 个来源文件的指纹全部变化。重新导出 1173 个数值组、534 个条件、3459 个分支定义、73 个事件池并核对来源 SHA256，没有绕过版本校验。
- `SaveSystem.CreateSaveData` 新增 `includeStoryLog` 布尔参数，无参数反射失效。当前状态快照显式调用 `CreateSaveData(false)`，再调用 `StoryLogData.Save(save, false)` 保存完整当前位置历史。普通原生存档继续由原生调用决定剧情起点范围。
- 新版显示 `StoryLogData`，旧 `Fungus.NarrativeLog` 中的 MOD 判定说明不会显示。说明改接新回想；直接恢复期间防止重建对白重复记录，载入已存历史允许执行，结束与异常后释放保护。迁移和内部数据载入补齐原生回想载入；严格比较仍包括回想，未忽略或覆盖差异。
- 新版 StatGroupVariable 增加 All/Any（全部非零、任一非零）；原生预览、索引读取、随机结果可达性计算均补齐。负数按非零处理，空集合与原生语义一致，未知运算不能猜成零。
- 更新变化的条件名称。导出器按原生 `story/chinesetraditional/` 资源路径解析，避免同名旧语言脚本覆盖正在使用的脚本。

## 用户验收

1. 冷启动直接读养成档：日期提示、F10、建筑及行动事件预览可用；固定一个可触发事件，确认实际触发一致。
2. 稳定对白、普通选项、投骰前分别存读档；核对当前位置和继续后的剧情、金钱及属性，F8 能返回最近分支。
3. 打开回想：原生对白和 MOD 剧情判定可见；读档后对白不重复，继续一句后新增一次。原生存档点仍正常保存。
4. 检查 F9 三项上限、骰子悬浮及指定、战斗跳过等实际界面。
