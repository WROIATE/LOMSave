# 0.25.13 冷启动事件提示验证

游戏版本：release_1.0.6000.5。以下为发布前已完成的本机覆盖和验证记录。

## 改动

- 随插件提供与游戏文件匹配的只读事件索引。冷启动直接读取养成档时，无需先进入剧情，即可计算日期未读提示与 F10 特殊事件汇总。
- JSON 解析和游戏版本、6 个配置来源文件的 SHA256 校验在后台执行一次，不预载剧情场景或全量资源。游戏更新导致索引失配时停用该后备数据，避免使用过期条件；进入剧情后可继续使用原生配置。
- 条件读取当前游戏数值；随机条件、计数式选择和无法确定的值保持未知，不执行 Lua、抽随机数或触发检查点。原生配置出现后优先使用原生配置。
- 每帧检查一栋建筑，缓存菜单路由和变量引用；不缓存事件条件结果，状态变化后重新检查，空闲不重复扫描。
- 安装包增加 `BepInEx/plugins/LOMSaveProbe.StoryEvents.json`，与 DLL 同目录保留。
