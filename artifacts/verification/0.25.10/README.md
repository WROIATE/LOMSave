# 0.25.10 死亡页读取游戏

死亡演出结束后，右下角在“回主选单”上方增加“读取游戏”，直接复用原生读档列表，包含 50 个手动槽位、原生自动档、最近行动及最近分支。按钮复制原生字体、颜色、悬停效果与尺寸。关闭列表后回到死亡页，也支持 Esc 取消。

GameOver 场景没有 LoadGamePanel、PlayerInputController 或暂停菜单输入映射。插件在首次原生读档面板 Awake 前缓存一个未初始化的休眠模板，仅在死亡页首次点击时创建列表；清除根面板指向原场景的打开/关闭回调，使用原生槽位、删除确认和读取流程。死亡页不启用依赖不存在输入宿主的手柄图示及 InputButton，Esc 由仅在列表可见时运行的组件处理。没有逐帧资源扫描，也不会为打开列表额外加载主菜单场景。

验证结果：

- 23 组完整回归通过；最终构建的 465 个原生引用、164 个 Harmony 目标、59 个反射成员检查通过，24 个补丁类注册。
- 实机读取原有“战斗”自动档，原生投降后进入与用户截图相同的“砍死”页面。
- 演出完成后出现按钮；字体、尺寸和右对齐位置与“回主选单”一致。
- 点击直接显示完整原生列表；点击右上角关闭返回死亡页，重复打开正常，最终构建的 Esc 关闭正常，未出现多余手柄图示。
- 从死亡页列表点击“最近分支”，恢复至 S0003_02_07 的原选择；continuation_state_validated 的 differenceCount 为 0，historicalStatementsExecuted 为 0。
- 最终实机运行的 Player.log 中 Exception / Error 为 0。
- 测试前备份 109 个存档文件、9 个配置。测试后归档并还原 5 个被自动保存或死亡计数修改的文件，109 个存档及 9 个配置的哈希全部与测试前一致；未修改属性、偏好或手动存档。
