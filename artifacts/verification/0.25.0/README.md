# 0.25.0 稳定对白直接续接验证

验证日期：2026-10-19～20。游戏 `release_1.0.6000.4`，Unity `2020.3.49f1`，BepInEx 6 Mono x64，保留原有 ScriptTrainer 1.1.2。最终 DLL SHA256：`95EA3B0F2616D68D8792125E69C4E8A64126A1235D7269EAE823392AC81EC1B8`。

本轮范围为存读档、事件固定和预览。验证完成后已恢复用户正常退出后的存档及配置：179 个存档文件、5 个配置文件逐一核对 SHA256，184 项全部一致。测试存档另行归档，游戏目录保留最终 DLL。

## 改动

- 第 12 版自由存档记录对白位置、当前分支、续接变量、场景、立绘、插图及声音状态，从保存的语句直接继续，不执行其前面的剧情语句。
- 手动保存只接受文字展示完成且正在等待点击的稳定对白，同时检查立绘移动、淡入淡出等演出。选项与骰子仍由最近分支自动档记录。
- 恢复时校验存档身份、脚本指纹和检查点；不匹配时拒绝直接恢复。当前分支沿保存路径续接，不用已变化的旗标重新决定之前走过的分支。
- 原生剧情入口自动档仍使用原生读档；旧自由档保留兼容恢复，读回后重新保存即可生成直接续接档。
- 脚本计划按需生成，最多缓存 24 份；保存检查在存档操作时执行，未加入逐帧扫描全部场景对象。

## 离线检查

- 最终版本 20 组回归通过，涵盖扣费／奖励不重放、同名局部变量作用域、先前分支不重判、选择快照、改选分支、分支后的共同剧情、跨脚本全局变量等。
- 当前游戏 2068 份脚本、77717 个续接点编译检查通过，无编译失败；这项检查不等同于逐条剧情实机游玩。
- 游戏接口检查通过：447 个原生引用、145 个 Harmony 目标、49 个反射成员、21 个补丁类。
- 原生 Lua 测试中的 Unity 资源加载异常为独立测试进程的预期降级情形，测试继续完成，最终结果为全部通过。
