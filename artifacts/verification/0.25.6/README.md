# 0.25.6 未读事件提示与日期事件记录

日期旁只统计当前可做且未读的事件。打开当前剧情汇总，或查看今天详情中的当前事件，即将该页列出的事件标为已读。已读按事件代码保存，重复刷新、跨旬、读档、重启不重复提醒。过期或暂不可做的未读事件不计入提示；再次可做且仍未读时继续提示。

养成地图完成一次稳定检查后，自动记录该年、月、旬曾满足条件的事件及触发方式。全年表标注“剧情记录”，点击日期可查看。记录和已读属于个人日历数据，跨读档、周目保留；记录只代表观察到的可触发时段，不代表整旬随时可做，也不补算未经历的日期。随机事件保留随机说明。文件为 `BepInEx/config/LOMSaveProbe.CalendarEvents.json`。

验证结果：

- 22 组回归全部通过，其中事件检查 50 条断言、持久化等数据检查 40 条断言。
- 游戏接口检查通过：459 个原生引用、158 个 Harmony 目标、49 个反射成员，22 个补丁类注册。
- 实机第三年十月下旬，4 个未读特殊事件显示 `◇ 4`，无需打开日历即写入该旬记录。
- 点击查看后提示消失，F10 仍能查看全部 4 个事件，全年表显示“剧情记录 4”。
- 正常退出并重启，读取第四年二月中旬原生剧情档后，仍可回看第三年十月下旬的 4 条记录及触发方式。
- 再读第三年十月下旬养成档，实际可触发数仍为 4，已读数 4，未读数 0，日期旁不再出现提示。
- 新事件出现、未读事件过期、恢复可做、同事件跨旬、重复扫描无重复记录与空闲帧不重写文件，由生产逻辑回归覆盖。
- 观察记录按变更合并、延后写入；查看时仅在已读变化后写入。沿用每帧一个建筑的增量检查，没有增加每帧事件池扫描。
