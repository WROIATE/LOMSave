# 0.25.21 条件剧情事件选择验证

日期：2026-10-26（Asia/Shanghai）。游戏：release_1.0.6000.5。仅加载 LOMSave Probe，不安装 ScriptTrainer。

## 覆盖范围

- 扫描当前游戏 2199 个剧情脚本，找到 16 个脚本、13 个判定定义的 31 处随机 Switch 调用，均由新路线扫描器识别。清单见 [coverage.json](coverage.json)。这是全量静态检查，不代表逐条实玩了 31 处剧情。
- 涉及炼丹、锻造、后山、广场、崆峒各行动、药铺、旅行及章节剧情。普通事件池继续沿用原生选择；新增支持带随机值的条件判定，不开放纯属性判定或次数控制判定的强制修改。
- 日期、好感、旗标及到达路线条件保留；未知条件不能指定。执行时使用当前脚本与判定代码核验，原生 Lua 负责奖励和后续跳转。

## 实机操作

1. 读取崆峒日常剧情档，中键铁拳巷打开预览，再进入“查看事件”：显示行动页签与“小梅邀约·触发 / 不触发”。固定触发，进入铁拳巷消耗一次行动，修练后准确进入小梅“阿活出来玩！”对白。
2. F8 返回铁拳巷选项，恢复校验 `differenceCount=0`，行动、金钱与心相回到分支时的数值。F10“本段剧情分支”可打开选择，固定设置保留。单次指定“不触发”优先于固定触发，修练后打开原生修练面板，关闭后正常回到日常。
3. 正常退出后冷启动，直接读唐门养成地图档，不先进入 Story。日期图标和 F10 显示叶云舟条件事件；炼丹房预览包含条件、单次指定和固定按钮。固定“叶云舟·触发”后进入炼丹，原生剧情出现叶云舟被二师兄使唤的事件。
4. 检查建筑时发现男弟子房休息事件在下一层菜单，原建筑扫描漏列。补上跨脚本嵌套菜单路线并回归后，再次冷启动直接读养成档：男弟子房预览已列出福韫讲法等休息事件，并与四师兄页签分开；炼丹房原页签和重启前的固定选择仍正常。
