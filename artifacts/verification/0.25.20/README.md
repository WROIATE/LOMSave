# 0.25.20 骰子选项悬浮高亮

日期：2026-10-25。

原因：旧插件的指针移入/移出事件分别调用原生 DiceOption.Select / UnSelect。独立整合只接入短按指定结果和长按/中键预览，遗漏悬浮事件，因此结果仍可指定，但悬浮时没有底图、文字和箭头变化。

修复复用同一原生显示接口，接入现有选项输入组件的移入/移出事件。仅在投骰前可选择状态显示悬浮效果；预览、开始投骰、关闭和复用时清理临时高亮。在结果显示前解除临时高亮的归属，避免随后移出鼠标时擦除原生结果高亮。没有新增每帧扫描或状态快照。

验证：33 项集成断言通过，覆盖原有骰子和单挑逻辑，以及悬浮不修改结果/不启动投骰、跨选项移动、迟到的移出、预览阻止、投骰开始清理、实际结果高亮保留、关闭清理。游戏接口检查通过：484 个原生引用、187 个 Harmony 目标、90 项反射成员、28 个补丁类。

按用户此前明确授权，备份后覆盖磁盘 DLL，继续由用户自行重启；未操作或重启正在运行的游戏，未修改玩家存档和配置。本轮未进行新版本实机界面验证，也未推送或发布。
