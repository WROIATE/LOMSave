# 0.23.0 最近分支自动存档与 F8 返回（待实机验证）

日期：2026-10-19，Asia/Shanghai。接口检查对象为本机 `release_1.0.6000.4`。

## 功能

- 独立的 `auto_branch` 槽，读档页显示“最近分支”，分类位置标注“F8 返回”；与手动档、“最近行动”和原生自动档分别保存。
- 在统一剧情命令检查点建立后、原生选择或骰子执行前保存，包括普通选择、限时选择和骰子判定。保留此前选择历史，读回后停在待选择／待投骰的流程。
- 普通空菜单、只有一个可选按钮的确认页和普通台词不覆盖之前的分支，避免投骰后的“继续”按钮取代投骰点。原生隐藏／不可选行的 `~` 标记参与选项数判断，支持 JSON 数组与 Lua 序号表；无法可靠解析的菜单保留自动存档。限时单选仍保存，保留超时分支。
- F8 在可操作的剧情或养成界面按原生自动读档流程读取，保留源档的手动槽位。切换前取消剧情自动播放／快进；菜单、回想、输入框、预览、日历、非交互剧情、场景加载及重放期间不响应。其他场景可使用游戏允许的原生读档菜单。
- 快捷读取先验证附加记录版本、分支检查点、时间、内容哈希与脚本。缺失或不匹配时提示并拒绝，不默默跳到剧情开头。
- 每次实际新分支覆盖最新一档；重复读取仍返回该档，直到遇到下一分支。不是无限撤销历史，不改写原生骰子随机规则。

## 实现约束

复用原生 `SaveSystem.AutoSaveData`、既有精确重放及存档附加记录，新增逻辑不扫描后续剧情资源。检查点每次最多保存一次，原生写入失败不会标记为保存成功。重放判断发生在目标到达／拒绝清除状态之前，避免重放中间的选项覆盖有效分支档。存档诊断新增实际 `elapsedMs`，游戏内写盘耗时仍待验证。

自动档行复用原生模板，沿用既有布局适配；生产布局函数的离线测试验证两个扩展槽加入后，所有行保持一致缩放和原有区域总高度。没有制作或冒充实机截图。
