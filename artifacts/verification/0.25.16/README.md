# 0.25.16 自由档商店恢复修复验证

验证日期：2026-10-25。游戏版本：release_1.0.6000.5。

## 故障与原因

使用玩家原有“最近分支”档，恢复目标为 `ch2_2_5_4` 的第 46 个检查点（投骰前）。0.25.15 已加载背景、立绘，但库存不一致触发严格校验，主动停止剧情续接；本次不是资源加载卡住。

存档内商店记录为十一月商品 `3111`、触发记录 `1-11`，游戏当前日期为十二月。恢复时有两条额外改库存的路径：

- 原生 `ShopPanel.Awake` 即使创建的是隐藏商店界面，也会调用 `UpdateItemFromMission` 补入当月商品。
- 另装的 ScriptTrainer 在进程首次执行商店载入的后置补丁中调用 `NewShop`，将已保存库存替换成当月库存。

修复只在自由档直接恢复期间，分别限制商店载入范围内的额外 `NewShop` 和商店界面初始化范围内的额外任务补货。异常时释放范围并继续抛出原异常。保留原有严格校验；不忽略库存差异，不在校验前强行覆盖属性、金钱或库存。原生读档和实际任务、换月补货不套用此限制。

## 实机结果

- 冷启动后读取同一原始故障档：两条额外刷新均被阻止，准确恢复投骰前界面；状态差异为 0，历史剧情语句执行数为 0，恢复遮罩约 1.997 秒。
- 点击“启动”完成投骰，再点击“继续”：正确进入峨眉弟子对白“够了，够了，越说越不成体统了。”。
- 对白完整显示后按 F8 再读原分支：再次准确恢复投骰前界面；状态差异为 0，历史剧情语句执行数为 0，恢复遮罩约 1.362 秒。
- 两次读回的贡献度 189、心相 82、行动数 4、银两 18222 与原分支一致。
- 结束时游戏留在原分支投骰前。109 个原存档及附属文件、9 个配置文件与测试前备份的哈希均一致，目录没有新增玩家文件。

耗时是从读档恢复遮罩出现到画面恢复的实测值，不包含在读档菜单停留和人工操作时间。上述结果针对本次故障档及操作路径，不代表全游戏所有剧情已逐一验证。
