# 0.25.2 内置 F9 入口

状态：在 `release_1.0.6000.5` 完成独立安装与旧插件共存实测，21 组回归与游戏接口检查通过。测试前的存档、配置和原插件已还原，新版主 DLL 已安装。

## 改动

- F9 入口直接编译进 `LOMSaveProbe.dll`，安装包不再要求另装修改器。
- 打开游戏原生测试面板，继续使用此前优化的属性加减、变心和养成点数、中文旗标及代码悬浮提示。
- 打开时保存并暂停剧情与游戏速度，F9、Esc、原生关闭或场景销毁后恢复；输入框、其他窗口及加载期间不打开。
- 已加载并启用 `ScriptTrainer.Jim97.Mortal` 时，内置 F9 将入口交给原插件，避免双重开关。原插件停用时启用内置入口。
- 缓存原生面板引用，只有按键时检查入口与环境，不逐帧扫描场景或枚举插件。
- 禁用仅该面板及子节点的 DevelopmentOnly 销毁逻辑，避免正式版首次打开就销毁；临时挂到可见父节点，关闭后恢复原层级。
- 打开时允许面板内部加减按钮，拦截背景操作与改变剧情速度的快捷键。
- 原版 ScriptTrainer 未附分发许可证，未将其二进制、源码或个人配置加入安装包。新增入口为独立实现；原作者来源保留在致谢中。

## 离线验证

44 项内置入口测试通过：无修改器时打开、关闭、暂停恢复、原生关闭／销毁、场景替换、外部修改器兼容、隐藏状态页的父节点、正式版销毁标记、内部按钮与背景区分、其他界面和加载拦截、激活失败后的恢复。原有 43 项属性与旗标数据测试通过。

21 组完整回归通过。游戏接口检查通过：449 个原生引用、145 个 Harmony 目标、49 个反射成员、21 个补丁类。脚本编译器和存档格式未改变，本轮没有重新执行完整剧情语料编译。

## 实机验证

最终实测已移除临时诊断工具，直接发送 F9、Esc 和鼠标操作。单独安装时的启动日志确认只加载一个插件。

- 养成界面 F9 打开；变心 `0 → 1 → 0`，按钮生效；中文旗标提示仅显示一次名称与代码 H01001；Esc 正常关闭。
- 原生剧情自动档载入后，F9 打开并再次关闭，仍停在“老爷，接下来怎么办才好？”；点击后进入南宫深的下一句“这……。”，暂停已解除。
- 恢复本地已有 ScriptTrainer 1.1.2 后，F9 能打开和关闭增强面板，变心加减生效；日志中没有内置入口的打开事件，确认沿用旧入口。
- 183 个存档文件、5 个配置文件共 188 个哈希校验一致；原 ScriptTrainer SHA256 一致；临时诊断插件已移出游戏目录。
