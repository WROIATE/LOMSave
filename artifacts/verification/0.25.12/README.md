## 改动

- 在解锁按钮前记录原版存档权限。原版允许的剧情菜单及非剧情场景走原生存读档，不生成自由档续接信息；仅额外开放的剧情存档检查稳定对白。
- 事件已读与观察记录写入各存档的 `.lomsavecalendar.json`，校验原生存档时间和 SHA256 后恢复。旧版日历保留行动记录，缺失的事件快照按未读处理；不导入无法确定所属周目的旧全局记录。
- 新周目清空事件已读、观察与行动记录，保留手动日历备注和固定事件等全局偏好。取消原先全局事件文件的延时写入。

## 边界与恢复

冷启动直接读取养成地图时，原生特殊事件池尚未初始化。现有日历会注明需首次进入剧情后补齐；本次未改变该数据初始化方式，也未加入启动时全资源扫描。已读状态恢复测试在原生事件数据就绪后进行，不能据此声称该冷启动限制已消除。

实测前先将当前进度保存到原先空置的 004，再备份 113 个存档相关文件和 9 个配置文件。测试后校验恢复备份、归档新建的 005—008 测试档。Steam 启动时重新同步的测试文件亦按 SHA256 核验后归档。原有手动存档未覆盖，最终游戏停在 004。

本轮验证时未推送 Git 或更新 GitHub Release；改动随 0.25.13 一并发布。
