# 活侠传自由存档增强版 0.22.3

完整功能、原版差异与编译说明见[仓库 README](https://github.com/WROIATE/LOMSave)。

本项目用于学习与技术研究，不保证程序稳定性或与所有游戏版本、其他 MOD 的兼容性。使用可能造成游戏卡顿、崩溃、存档损坏或进度丢失。请先备份存档，自行评估并承担使用风险。

## 安装文件

使用 BepInEx 6 Mono。本版实机验证环境为 `release_1.0.6000.3`、Unity `2020.3.49f1`、Windows x64；整体功能实测记录见仓库 `artifacts/verification/0.22.0/`，全年日历与 F9 标题见 `artifacts/verification/0.22.1/`，旗标行对齐与悬浮名称去重见 `artifacts/verification/0.22.2/`，滚轮回想触发保护与诊断见 `artifacts/verification/0.22.3/`。

`release_1.0.6000.0` 游戏程序为 64 位，需使用 **BepInEx 6 Unity.Mono Windows x64**。沿用旧版 x86 的 `winhttp.dll` 会导致整个插件框架不加载，设置项也不会出现；需要更新引导器，不能只覆盖插件 DLL。

从 [Releases](https://github.com/WROIATE/LOMSave/releases) 下载对应版本的 `LOMSave-enhanced-v版本号.zip`，将包内的 `BepInEx` 文件夹合并到游戏根目录。安装包包含下表文件和 `LICENSES` 目录；本安装包不包含 BepInEx 框架，需先有可用的 BepInEx 环境。

| 文件 | 位置 |
| --- | --- |
| `LOMSaveProbe.dll` | 游戏目录 `BepInEx/plugins/` |
| `Newtonsoft.Json.dll` | 游戏目录 `BepInEx/plugins/` |
| `YamlDotNet.dll` | 游戏目录 `BepInEx/plugins/` |
| `LOMSaveProbe.CodeNames.yaml` | 游戏目录 `BepInEx/config/` |
| `Newtonsoft.Json.LICENSE.txt`、`YamlDotNet.LICENSE.txt` | 保留第三方许可证 |

把原来的 `LOMSave.dll`、`LOMSave2.dll` 或旧版增强插件移到插件目录外，只启用一份存档插件，然后重启游戏。

## 使用要点

- 游戏原生保存／读取菜单支持剧情内存档，手动档槽扩展为 50 个，档旁可编辑备注。
- “最近行动”在唐门养成和兼容的外地行动菜单中执行耗行动操作前更新，读档可回到行动前。
- 长按选项或养成建筑约 0.5 秒查看影响／事件，也可中键点击；0.2 秒后显示长按进度，右键关闭预览。
- 设置页“对话设定”提供自动播放速度、按文本长度调整和实时剧情判定提示。
- 剧情判定会写入新回想；实时提示可选开启，消息逐条显示并依次淡出。
- 主名称表可编辑并自动重新加载；无说明的编码保留编号。
- 新版装备替换会显示装备名称与等级，弹珠台、对决及混战入口分别显示；名称表已更新至 5,949 项。
- 预览和实时判定固定使用游戏正文的思源宋体，避免菜单或对话框切换后误用行书。
- 读档恢复环境音的实际音量和渐变，避免已经静音的雨声重新响起。
- 事件预览默认隐藏确定不可触发的事件，可手动展开；“固定选择”跨读档、重启保留，每次触发仍检查条件。
- 四师兄弹珠右上角可快速结束，选择 0／30／60／100 分，对应未达门槛／三奖／二奖／大奖；奖励仍由剧情发放。
- 混战准备页和暂停页提供“直接胜利”，增加模拟表现，走原生属性、点数结算；金钱增加拾取比例和预算随机性，额外拾钱上限 2,500 两。
- 行动日历自动记录耗行动操作，可按月浏览并手动备注。新周目到同一游戏年月旬时，在左上角日期下方常驻提示备注。
- 鼠标滚轮向上打开剧情回想；窗口、输入框或滚动列表内不会误触。0.22.3 在滚轮事件结束后的帧再打开原生窗口，避免打开事件同时进入新建的滚动列表；重复滚动、场景切换和读档期间有触发保护，并记录打开耗时与异常。诊断快照改为 Ctrl+F10。
- F9 保留原生按钮和字体，角色数值补全为 54 项并支持滚动。变心每次 ±1（0–10），银两 ±500，其余沿用原生 ±5。增加养成点数会同步累计，累计点数也可单独调整。依赖现有 ScriptTrainer 等插件提供入口。
- 旗标保留原生 51 项，不再扩成全部旗标和分页；映射成中文，悬停仅显示一次名称和代码，提示框保持在屏幕内。两列旗标统一字体、固定字号和行高，名称、数值、加减按钮在同一行居中对齐，不再按名称长短缩放文字。四栏标题使用统一字号、字体和基线。没有可靠名称的保留编号，原好感度栏继续可用。
- F10 默认打开全年日期表格：12 个月 × 上中下旬，有备注的日期显示金色标记与摘要，今天有金色边框。点击日期进入详情，编辑后可返回总览，也可切换年份。
- 随机事件配置随剧情场景加载。首次直接读养成档时会提示数据尚未加载；进入一次剧情后缓存供养成地图使用。

精确位置记录是原存档旁的 `.lomsaveprobe.json`，行动日历是 `.lomsavecalendar.json`，存档备注是 `.note.txt`；备份时一起保留。日期备注和固定事件分别保存在 `BepInEx/config/LOMSaveProbe.CalendarNotes.json`、`LOMSaveProbe.Events.json`，迁移设备时一起复制。旧档不能补回此前没有记录的行动或精确台词位置。静态预览和复杂剧情的恢复仍有范围限制，详见仓库说明。
